#################################################### v0.1 Release Features #####################################################
################################################################################################################################

[Local Multiplayer Controls] 
- Player 1 use WASD keys; Player 2 use Arrow keys
- Pick up items added from drawmode in 16-slot inventory

[PvP Gamemode] 
- Two monsters navigate through blocks to eat the most randomly spawned food in 30 seconds

*[Drawmode - Sandbox Tools]
- Edit the map with pen, eraser, input, and flip-flop tools.
- Brush sizes small, medium, large; horizontal/vertical/diagonal lines, cross, x, and square shapes.
- Select input tile to add custom tiles including monsters, food, and more
- Spawn, add, and clear food
- Customizable map dimensions on startup

*[Developer Mode]
- *Command interface: ustomizing with fields
- *GUI with Sandbox Buttons and Editor Mechanics (Select Tile, Saved Tile)

*[Design/Save Maps]
- JSON File Game Tile Map
- Save and fill with space tiles if out of bounds 
- Separate Map Data Object for customized maps with tiles?
- Better tile management? --> Create finite tileTypes with certain functions
- Json Receiviver function to find key value pairs

*: work-in-progress feature
