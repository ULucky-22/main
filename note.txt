[Quick Description] Offline 2D Survival Game, potential for multiplayer?
[Inspiration] Minecraft/Terraria/Stardew-like? Classic games snake, tron

[Base Game] Face off as either the Red Monster or the Blue Monster to eat the most food before the timer ends!
- Randomly Generated Map
- Player versus Player (PvP) Gamemode - Offline Multiplayer Currently, Online Multiplayer Planned for Future Release
- Timer currently at 30 seconds.

[Sandbox Mode] Use Sandbox Mode to play god in the game. Use drawing tools to build the map the monsters face off in, spawn food, 
paint, add players, and more!
- [Drawmode] Edit the map with pen, eraser, input, and flip-flop tools.
    - Brush sizes small, medium, large; horizontal/vertical/diagonal lines; + Cross and x Cross shapes
    - Select input tile to add custom tiles including monsters, food, and items
- Spawn, add, and clear food
- Customize map dimensions on startup
- Design and save game to JSON or local session

[Developer Mode]
- New! Press F3 to view the Debug Menu
- New! Press F2 to view the Position Coordinates Helper
