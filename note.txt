[Quick Description] Offline 2D Survival Game, potential for multiplayer?
[Inspiration] Minecraft/Terraria/Stardew-like? Classic games snake, tron

[Adventure Mode]
- In the works!

[PvP Mode] 
- Current Base Game Mode
- Face off as either the Red Monster or the Blue Monster to eat the most food before the timer ends!
- Randomly Generated Map
- Player versus Player (PvP) Gamemode - Offline Multiplayer Currently, Online Multiplayer Planned for Future Release
- Timer currently at 30 seconds.

[Sandbox Mode] 
- Use Sandbox Mode to create your own game. 
- Use drawing tools to build the map, spawn food, add items, paint, players, and more!
    - Edit the map with pen, eraser, input, and flip-flop tools.
    - Brush sizes small, medium, large; box; horizontal/vertical/diagonal lines; + Cross and x Cross shapes
    - Select input tile to add custom tiles including monsters, food, and items
- Customize map dimensions on startup
- Design and save game to JSON file or local session

[Developer Mode]
- New! Press F3 to view the Debug Menu
- New! Press F2 to view the Position Coordinates Helper

1. Game Variables
    - Held in 'sessionMapData' object for 1-object save-game.

    - Assets: To define all assets used in game, for future use for theme packs, etc.
